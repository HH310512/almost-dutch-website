# Project: Almost Dutch — website & prototype

## Wat dit is
Landingspagina (almostdutch.nl) plus speelbaar prototype (/test) van een
cultuurapp voor expats. Statische site, geen backend, geen build-stap.

## Techniek
- Losse HTML/CSS/JS. Geen framework, geen npm-pakketten toevoegen.
- Tweetalig via data-i attributen (EN standaard, NL vertaling in het script).
- Formulieren via Formspree: wachtlijst maqrwlnl, feedback xdaqogow.
- Hosting: GitHub Pages. Wat op main staat, staat live.

## Huisstijl
- Oranje #FF6B35, Delfts blauw #2743B0, inkt #14203E, achtergrond #FAFBFD.
- Fonts: Bricolage Grotesque (koppen), Schibsted Grotesk (tekst).

## Belangrijk om te weten
- test/index.html is GEGENEREERD uit dutch-survival-guide.jsx (buiten deze repo).
  Wijzig de app-inhoud daar, niet in test/index.html.
- index.html in de root = de site (robots: index). test/index.html = de app (noindex).
- Geen animaties op content-elementen; die veroorzaakten een weergavebug.

## Spelregels
- Maak nooit een commit zonder dat ik het vraag.
- Verander nooit bestanden buiten deze projectmap.
- Geen wachtwoorden of sleutels in de code.
- Leg bij elke wijziging in twee zinnen uit wat je hebt gedaan en waarom.
- Antwoord in het Nederlands.

## Klaar is
Site laadt onder 2 seconden, werkt op telefoon, formulieren komen aan.
